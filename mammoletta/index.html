How to get it into Design Space
  1. Save the file, then open Cricut Design Space.
  2. Choose Upload, then Upload Image, and pick the file.
  3. An SVG arrives with its colours as separate layers. For the sticker PNG choose Print Then Cut.
  4. Check the size on the canvas before you cut.

How to get it onto the Skitch
  1. Open this page on the phone that has Artspira, or send the PES file to it.
  2. In Artspira, use the option to import an embroidery file and pick the PES file.
  3. Check it fits the 4 × 4 in hoop, then send it to the machine.
  4. Thread the colours in the order listed above. The machine stops for each change.

Stitch a test on scrap fabric with stabiliser first. Simple shapes with a few colours give the best results.
